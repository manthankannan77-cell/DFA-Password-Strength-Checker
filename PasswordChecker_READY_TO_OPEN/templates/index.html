Top row: fewer than 8 characters. Bottom row: 8 or more. The 8th character moves the machine down a row (and also sets a digit or special flag if it is one). Letters and repeated flags keep the machine in the same state, so those self-loops are not drawn. Bright glowing states and lines show the path your password has taken.

The DFA tracks three monotonic flags: L = length ≥ 8, D = a digit has appeared, and S = a special character has appeared. Each combination is a state qLDS. The state output determines the displayed strength. This is an educational demonstration, not a complete security audit.
